# Fictional firms

`seed.csv` holds the three fictional firms used by `contracts/mocks/`, with the same `registry_id`s, so CLI output lines up with the dashboard mocks. It is not the real KNF register. Columns: `id, name, aliases, type, country, website_domains, source_url`; list fields are separated by `|`. Point `REGISTRY_CSV` at another file to use a different registry.
