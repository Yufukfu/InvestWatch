# contracts (owner C)

JSON Schema for `ScrapedDocument` and `Finding`, plus example mock data (`documents.json`, `findings.json`) so the scraper, analytics and dashboard can work independently. Until the schemas exist, the source of truth is [`doc/integration-plan.md`](../doc/integration-plan.md) §3 (`ScrapedDocument`) and §4 (`Finding`).

## Rules that are easy to get wrong

- Version **v1** is frozen from Sat 14:30. A change needs the whole team's agreement and a version bump, and an OpenSpec change that names it.
- Producers validate against the schema before inserting; consumers must tolerate additive fields.
- A schema change updates, in the same PR: the schema, the mocks, `doc/integration-plan.md`, and the tests of every consumer.
- Minimum viable `ScrapedDocument` is `id, platform, url, fetched_at, text, source_kind`; `blocks` and screenshots are optional and their absence means "not applicable", never "pass".
- Time is UTC ISO-8601, ids are UUID v4 generated by the producer.

## Done

Schemas validate the mocks, and the mocks validate against the schemas in a test.
