# Architecture decision records

One file per decision: `NNNN-short-title.md`, copied from `0000-template.md`. ADRs are written by a human; agents may draft options and evidence, never the decision or its rationale. Never auto-merge an ADR. A decision is superseded by a new ADR that links the old one, not edited away.

Write one when a choice is hard to reverse or a teammate will ask "why": fetch library, queue, storage layout, contract changes.
